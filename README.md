## 📖 نبذة عن المشروع

**الميزان** نظام محاسبي ونقاط بيع (POS) متكامل، مصمم للأعمال الصغيرة والمتوسطة. يعمل من أي متصفح (موبايل / كمبيوتر) مع **مزامنة سحابية فورية** عبر Firebase.

---

## ✨ الميزات الرئيسية

### 🛒 نقاط البيع (POS)
- فواتير بيع (نقدي، آجل، فيزا، محفظة، تحويل، تقسيط)
- فواتير ضريبية وعادية
- خصومات (نسبة / مبلغ)
- كوبونات ونقاط ولاء
- طباعة الفواتير + QR Code + واتساب

### 📦 المخزون
- إدارة المنتجات (إضافة/تعديل/حذف)
- تتبع الكميات وأسعار الشراء والبيع
- تنبيه المخزون المنخفض
- بحث بالاسم أو الباركود
- توزيع المخزون بين المستودعات

### 👥 العملاء والموردين
- إدارة كاملة مع أرقام الهاتف والواتساب
- تتبع المديونيات
- إرسال تذكير بالديون عبر واتساب

### 💰 الخزائن والمدفوعات
- خزائن متعددة (نقدي، بنك، محفظة، فيزا)
- رصيد افتتاحي لكل خزنة
- حركات تلقائية لكل عملية
- التحصيل من العملاء + السداد للموردين
- إيصالات استلام ودفع

### 📚 المحاسبة
- دليل حسابات كامل (30+ حساب افتراضي)
- قيود يومية تلقائية لكل عملية
- ميزان المراجعة
- قائمة الدخل
- الميزانية العمومية

### 📊 التقارير
- يومي / شهري / سنوي
- البائعين + المنتجات + العملاء
- تصدير CSV + طباعة PDF

### 🏭 إدارة الموارد (ERP)
- مستودعات متعددة
- أذون إضافة وصرف
- تحويلات بين المستودعات
- تسوية الجرد
- مخزون أول المدة
- فروع + عملات

### 👥 الموظفين (HR)
- إدارة الموظفين
- تسجيل الحضور والانصراف
- حساب ساعات العمل
- صرف الرواتب

### 🤖 الذكاء الاصطناعي
- توقع المبيعات للأسبوع القادم
- التنبؤ بالمنتجات التي ستنفد
- تحليل سلوك العملاء
- اقتراح أسعار ذكية

### 🔐 الأمان
- تشفير كلمات المرور (PBKDF2)
- Rate Limiting للحماية من التجربة المتكررة
- جلسات بمهلة زمنية
- 2FA (اختياري)
