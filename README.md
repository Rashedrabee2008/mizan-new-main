# ⚖️ الميزان Pro — نظام محاسبة ونقاط بيع

**الإصدار 18.0.0**

نظام محاسبي متكامل + نقاط بيع + مزامنة سحابية فورية + Multi-Tenant (جاهز للبيع).

---

## 🎯 المميزات الرئيسية

### 🛒 نقاط البيع
- فواتير بيع (نقدي، آجل، فيزا، محفظة، تحويل، تقسيط)
- فواتير ضريبية وعادية
- خصومات (نسبة/مبلغ) + كوبونات + نقاط ولاء
- طباعة الفواتير + QR Code + واتساب

### 📦 المخزون
- إدارة المنتجات (CRUD كامل)
- تتبع الكميات وأسعار الشراء والبيع
- تنبيه المخزون المنخفض
- توزيع المخزون بين المستودعات

### 👥 العملاء والموردين
- إدارة كاملة + واتساب
- تتبع المديونيات
- كشوفات حساب

### 💰 الخزائن والمدفوعات
- خزائن متعددة (نقدي، بنك، محفظة)
- رصيد افتتاحي لكل خزنة
- حركات تلقائية مرتبطة بكل عملية
- التحصيل + السداد

### 📚 المحاسبة
- دليل حسابات كامل (25+ حساب)
- قيود يومية تلقائية لكل عملية بيع/شراء/مصروف/تحصيل/سداد/راتب
- ميزان المراجعة
- قائمة الدخل
- الميزانية العمومية
- كشوفات حساب تفصيلية

### 📊 التقارير
- يومي / شهري / سنوي
- البائعين + المنتجات + العملاء
- تصدير CSV + طباعة PDF

### 🏭 إدارة الموارد (ERP)
- مستودعات متعددة (رئيسي/فرع/مخزن/مرتجعات)
- فروع + عملات

### 👥 الموظفين (HR)
- إدارة الموظفين
- تسجيل الحضور/الانصراف
- حساب ساعات العمل
- صرف الرواتب تلقائياً بقيد محاسبي

### 🤖 الذكاء الاصطناعي
- توقع المبيعات للأسبوع القادم
- تحليل سلوك العملاء

### 🔐 الأمان
- تشفير SHA-256 لكلمات المرور
- Rate Limiting (5 محاولات / 15 دقيقة)
- جلسات بمهلة 24 ساعة
- Multi-Tenant (كل عميل له Store ID منفصل)

### ☁️ المزامنة السحابية
- **Real-time sync** (Firebase Realtime Database)
- **تعديل من الموبايل → يظهر على الكمبيوتر فوراً**
- **Auto push** كل 30 ثانية
- **Store ID** فريد لكل عميل
